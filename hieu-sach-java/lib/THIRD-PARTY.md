# Thư viện Java

CHAY-WEB.bat và Dockerfile tải bản phát hành từ Maven Central và kiểm tra SHA-256.

- **MySQL Connector/J 26.10.0** là driver JDBC cho MySQL. Giấy phép GPLv2 với Universal FOSS Exception được đính kèm trong JAR. [Mã nguồn Connector/J](https://github.com/mysql/mysql-connector-j)
- **Gson 2.13.2** đọc dữ liệu JSON trả về từ DeepSeek. [Giấy phép Apache 2.0 của Gson](https://github.com/google/gson/blob/gson-parent-2.13.2/LICENSE)

Graphviz/Viz.js được dùng để tạo các file SVG. `tests/ExportDiagram.java` sinh sơ đồ cấu trúc từ metadata của MySQL.
